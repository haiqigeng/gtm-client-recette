# Non-Goals

Do not use this workflow to:

- create, redesign, or complete a tracking plan;
- perform a GTM container audit, hygiene review, or cleanup;
- debug, repair, or recommend implementation changes;
- modify GTM, submit changes, create a version, or publish;
- automate Google credentials, MFA, CAPTCHA, payment, or irreversible actions;
- declare legal, privacy, or consent-policy compliance;
- infer a pass from an event name without payload and tag evidence;
- hide unknowns behind a generic diagnosis.

Record observed non-firing reasons, but leave root-cause diagnosis and fixes to a
separate requested task.
