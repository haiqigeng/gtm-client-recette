# Non-Goals

Do not use this workflow to:

- create, redesign, repair, or complete a tracking plan;
- run a general container audit, hygiene review, or cleanup;
- modify GTM or website code, implement fixes, submit GTM changes, create a GTM
  version, or publish;
- test server-side GTM clients, transformations, server requests, or
  browser/server deduplication;
- claim root cause beyond direct Preview, console, consent, or clearly marked
  inferred evidence;
- automate or store credentials, MFA, CAPTCHA, external verification, real
  payment, or irreversible actions;
- make legal or privacy-compliance decisions;
- claim vendor ingestion, attribution, reporting, or audience membership from a
  browser send attempt alone;
- run observation without a tracking plan or analyst-defined acceptance rule;
- invent arbitrary negative journeys or absence cases that the acceptance
  contract does not require;
- crawl unrelated website features after coverage is complete;
- infer `PASS` from an event name, page success, or tag firing alone.

Record observed failure reasons without turning the recette into debugging or
remediation work.
