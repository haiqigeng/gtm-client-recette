# Security Policy

The current supported release is **v5.0.0**. Only the latest published release
receives security fixes.

Report vulnerabilities privately through GitHub security advisories. Do not
open a public issue containing credentials, personal data, client domains,
container/destination IDs, tracking plans, screenshots, evidence files,
browser-session details, or run output.

All evidence persistence must pass through the central privacy/redaction
gate. Raw sensitive material belongs only in explicit quarantine and cannot be
loaded into verdicts or reports. Screenshots require an explicit privacy review.
Machine provenance and passing statuses must remain code-path controlled; agent
notes cannot fabricate observations or upgrade a deterministic result.
